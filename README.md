# Going Deeper - Save Importer Mod

Модифицированная версия игры **Going Deeper**, которая добавляет отсутствующую функцию импорта сохранений (миров) из внешнего хранилища обратно в игру. 

Оригинальная игра позволяет экспортировать миры, но не имеет встроенной кнопки для их обратной загрузки. Этот мод решает данную проблему, заменяя функцию кнопки **"About"** (О разработчике) в настройках игры на вызов системного проводника для выбора файла сохранения.

## 🛠 Особенности
* **Импорт миров:** Загрузка бэкапов прямо в слоты игры через кнопку "About".
* **Разблокировка Premium:** (Опционально, если в моде встроен обход покупок).

## 📥 Как импортировать сохранение
При стандартном экспорте игра автоматически добавляет приставку `gd_save_` к вашему файлу (например, `gd_save_su_sa_ca.bin`). **Для правильного импорта эту приставку нужно удалить.**

### Правильные названия файлов:
Перед тем как выбрать файл в игре, переименуйте его следующим образом:
* **Кампания:** `su_sa_ca.bin`
* **Выживание:** `su_sa_su.bin`
* **Песочница:** `su_sa_sa1.bin`, `su_sa_sa2.bin` или `su_sa_sa3.bin` (где цифра — это номер слота от 1 до 3).

### Инструкция:
1. Переименуйте ваш файл бэкапа согласно правилам выше.
2. Откройте игру и зайдите в **Настройки (Settings)**.
3. Нажмите кнопку **About**.
4. В открывшемся проводнике выберите ваш файл. 
5. Слот загрузится автоматически в нужный режим!

## ⚙️ Установка
Так как игра использует сплит-архитектуру (Split APKs), обычная установка файла может не сработать.

1. Скачайте файл `.apks` из раздела [Releases](../../releases).
2. Установите приложение **SAI (Split APKs Installer)** или **App Manager** из Google Play / GitHub.
3. Откройте SAI, выберите скачанный `.apks` архив и нажмите "Установить".
